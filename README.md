# Claude Cloud Playground

Agent skills (Claude Code format) for a coloring-book image pipeline:

- `skills/coloring-page-converter` – convert artwork to clean line art
- `skills/coloring-page-colorways` – generate colorway variants
- `skills/coloring-book-pipeline` – end-to-end bundle build with watermarking
- `skills/digidreamweaver-shop-pipeline` – package finished pages for a shop listing

Copy a skill folder into `.claude/skills/` in your project to use it.
