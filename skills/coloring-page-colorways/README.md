# coloring-page-colorways

Produces realistic and creative colored-in preview versions from blank coloring book line art.

## Features
- **Realistic Colorway**: Maps authentic color and lighting from the original art directly into the line contours.
- **4 Distinct Creative Themes**: Generates curated palettes (pastel, jewel, neon, monochrome + accent, ocean, sunset).
- **Procreate & Digital Art Assets**: Exports `.swatches` palette files and visual hex codes.
- **Dual Watermarking Policy**: Unwatermarked high-res files for customer download zips; watermarked preview images for listings and social media.
