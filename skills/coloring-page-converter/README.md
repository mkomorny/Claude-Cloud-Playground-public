# coloring-page-converter

Converts color images, photos, and AI artwork into clean, fill-ready, professional digital adult coloring book line art pages.

## Features
- **100% Pure Black and White**: Eliminates gray tones and shading that muddy digital coloring apps.
- **Bucket-Fill Ready**: Closes contours and performs leak-testing so drag-to-fill tools never bleed.
- **Aspect Ratio Integrity**: Never stretches, squishes, or crops original art.
- **Watermarking Separation**: Unwatermarked high-res masters (white JPG + transparent PNG + SVG) for buyers; diagonal tiled "PREVIEW DigiDreamWeaver" watermark on preview images.
- **QC Verification**: Generates `qc_report.json` with cell count, minimum cell area, and 400% zoom proof.
